# 🚀 Быстрый старт

## Пошаговая инструкция для начинающих

### Шаг 1: Установка Python

1. Скачайте Python 3.8+ с официального сайта: https://www.python.org/downloads/
2. При установке **обязательно** отметьте галочку "Add Python to PATH"
3. Проверьте установку, открыв командную строку (Win+R → cmd) и введите:
   ```
   python --version
   ```

### Шаг 2: Установка зависимостей

1. Откройте командную строку в папке проекта:
   ```
   cd D:\TelegramParser
   ```

2. Установите необходимые библиотеки:
   ```
   pip install -r requirements.txt
   ```

### Шаг 3: Получение Telegram API ключей

1. Откройте в браузере: https://my.telegram.org/apps
2. Войдите, используя свой номер телефона Telegram
3. Заполните форму создания приложения:
   - **App title**: TelegramParser (или любое название)
   - **Short name**: tgparser (или любое короткое имя)
   - **Platform**: Other
4. Нажмите "Create application"
5. Сохраните полученные данные:
   - **App api_id** - это ваш API ID (числовое значение)
   - **App api_hash** - это ваш API Hash (буквенно-цифровое значение)

### Шаг 4: Настройка Google Sheets

#### 4.1 Создание Service Account

1. Откройте: https://console.cloud.google.com/
2. Создайте новый проект:
   - Нажмите на выпадающий список проектов вверху
   - Нажмите "New Project"
   - Введите название: "TelegramParser"
   - Нажмите "Create"
3. Включите необходимые API:
   - В меню слева выберите "APIs & Services" → "Library"
   - Найдите "Google Sheets API" и нажмите "Enable"
   - Найдите "Google Drive API" и нажмите "Enable"
4. Создайте Service Account:
   - В меню слева: "APIs & Services" → "Credentials"
   - Нажмите "Create Credentials" → "Service Account"
   - Введите имя: "telegram-parser-bot"
   - Нажмите "Create and Continue"
   - Пропустите назначение ролей (нажмите "Continue")
   - Нажмите "Done"
5. Создайте ключ:
   - Найдите созданный Service Account в списке
   - Нажмите на него
   - Перейдите на вкладку "Keys"
   - "Add Key" → "Create new key"
   - Выберите формат "JSON"
   - Нажмите "Create"
   - Файл автоматически скачается

#### 4.2 Настройка Google Таблицы

1. Откройте: https://sheets.google.com/
2. Создайте новую таблицу (нажмите "+" или "Blank")
3. Дайте таблице название: "Telegram Channels Data"
4. Скопируйте ID таблицы из адресной строки:
   ```
   https://docs.google.com/spreadsheets/d/1a2b3c4d5e6f7g8h9i0j/edit
                                         ^^^^^^^^^^^^^^^^^^^^
                                         Это ваш SHEET_ID
   ```
5. Откройте скачанный JSON файл с ключом
6. Найдите строку `"client_email"`, скопируйте email (выглядит как `название@проект.iam.gserviceaccount.com`)
7. В Google таблице нажмите кнопку "Share" (Поделиться) вверху справа
8. Вставьте скопированный email
9. Выберите права: "Editor" (Редактор)
10. **Снимите галочку** "Notify people" (уведомлять людей)
11. Нажмите "Share"

### Шаг 5: Настройка проекта

1. Переместите скачанный JSON файл в папку `D:\TelegramParser`
2. Переименуйте его в `service_account.json`
3. Скопируйте файл `env_template.txt` и переименуйте копию в `.env`
4. Откройте `.env` в текстовом редакторе (например, Notepad++)
5. Замените значения на ваши данные:
   ```
   TELEGRAM_API_ID=12345678
   TELEGRAM_API_HASH=abcdef1234567890abcdef1234567890
   TELEGRAM_PHONE=+79991234567
   GOOGLE_SHEET_ID=1a2b3c4d5e6f7g8h9i0j
   GOOGLE_SERVICE_ACCOUNT_FILE=service_account.json
   ```

### Шаг 5.1: Готовим Telegram-сессию для Railway/серверов

1. Запустите `python main.py` локально и пройдите авторизацию в Telegram. После успешного входа в папке проекта появится файл `session.session`.
2. Преобразуйте файл в Base64. В PowerShell это можно сделать так:
   ```
   [Convert]::ToBase64String([IO.File]::ReadAllBytes("session.session"))
   ```
   Скопируйте полученную строку (её лучше хранить как секрет).
3. В Railway → Variables добавьте переменную `TELEGRAM_SESSION_BASE64=<ваша строка>`.
4. (Опционально) если хотите хранить сессию в другом файле, задайте `TELEGRAM_SESSION_NAME`. По умолчанию используется `session`, что соответствует файлу `session.session`.

> При запуске в headless-средах (Railway, Docker, cron) Telethon не сможет спросить код подтверждения. Поэтому заранее подготовленная `session.session` позволяет запускаться без ручного ввода.

### Шаг 6: Первый запуск через веб-интерфейс

1. Откройте командную строку в папке проекта
2. Установите/обновите зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Запустите веб-приложение:
   ```
   python web_app.py
   ```
4. Откройте в браузере:
   ```
   http://127.0.0.1:8000
   ```
5. Вставьте список каналов (или загрузите `.txt/.csv`) и нажмите запуск.
6. При первом запуске Telegram может попросить авторизацию:
   - Вам придет код в Telegram
   - Введите его в консоли
   - Если у вас двухфакторная авторизация, введите пароль
7. После авторизации начнется batch-сбор постов за последние 10 часов по загруженному списку каналов.
> Каждый запуск дергает каналы из текущего списка пользователя и обновляет/добавляет посты в Google Sheets.

### Шаг 7: Автоматизация

#### Вариант А: Простой (планировщик в скрипте)

Запустите файл `run_scheduler.bat` двойным кликом. Парсер будет запускаться каждый час (в начале часа).

#### Вариант Б: Task Scheduler Windows

1. Нажмите Win+R → введите `taskschd.msc` → Enter
2. Нажмите "Create Basic Task" (Создать простую задачу)
3. Введите имя: "Telegram Parser"
4. Trigger: "Daily" (Ежедневно) и добавьте повторение каждые 1 час (Use "Repeat task every" → 1 hour)
5. Время: выберите старт первого запуска
6. Action: "Start a program" (Запустить программу)
7. Program/script: укажите путь к `run_once.bat` в вашей папке проекта
8. Нажмите "Finish"

## 🔍 Проверка работы

1. Откройте вашу Google таблицу
2. Вы должны увидеть два листа:
   - **Каналы** - информация о всех каналах
   - **Посты** - все собранные посты (с детализацией по реакциям)
3. Данные будут обновляться автоматически по расписанию

### Поля на листе «Посты»
- Название канала
- Время публикации
- Дата публикации
- Рубрика
- Содержание поста
- Есть медиа
- Ссылка на пост
- Просмотры
- Лайки (сумма всех реакций)
- Реакции (детали по каждому типу)
- Комментарии
- Удален (Да/Нет, автоматически отмечаем, если пост исчез из канала в анализируемом окне)

## ❓ Частые вопросы

**Q: Где найти логи?**
A: В папке проекта появятся файлы `telegram_parser.log` и `scheduler.log`

**Q: Как добавить новые каналы?**
A: Через веб-страницу `http://127.0.0.1:8000` — вставьте каналы списком или загрузите `.txt/.csv`. Редактировать `config.py` больше не обязательно.

**Q: Как изменить время запуска?**
A: Откройте `scheduler.py` и настройте расписание, например:
```python
schedule.every().hour.at(":00").do(run_update)  # каждый час
# или
schedule.every(2).hours.do(run_update)          # каждые 2 часа
```

**Q: За какой период собираются посты?**
A: В веб-режиме каждый запуск собирает посты за последние 10 часов по списку каналов из формы.

**Q: Не могу авторизоваться в Telegram**
A: Удалите файл `session.session` и попробуйте снова

**Q: Ошибка "Permission denied" в Google Sheets**
A: Убедитесь, что вы дали доступ Service Account email (шаг 4.2, пункты 6-11)

**Q: Можно ли запустить на сервере?**
A: Да, но нужно будет настроить автозапуск через cron (Linux) или systemd
